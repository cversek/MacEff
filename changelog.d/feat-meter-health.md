### Added

- **The usage meter raises its own faults and rolls its hour up** (`usage_meter`, `usage_share`): a transcript the lookup lost track of used to be baselined again at every Stop, so its calls were never counted, and nothing noticed. The meter now warns and records a `usage_meter_fault` event, at most once an hour per kind, when a file with an earlier event is about to be baselined again (it resumes from that event instead) and when tools ran in the last hour but the main transcript counted no calls. Each tick that counts calls also records a `usage_rolled` event, at most once a minute, and the hook line's `me X%/h` reads the newest one from the last 15 minutes instead of an hour of events on every tool call; with none that recent it computes the hour as before.
