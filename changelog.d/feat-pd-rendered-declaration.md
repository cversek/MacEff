### Changed

- **BREAKING (containers): an agent's primal daemon declaration comes from `agents.yaml`, written by the deployment where the agent can't change it** (`docker/scripts/start.py`, `models/agent_spec.py`, `pd/names.py`, `pd/core.py`, policy `persistent_layer` 10.1; MIS-0002-R33). A run executes as the agent, so a declaration in the agent's own home is one a run could rewrite before the daemon next starts. Each agent now declares its daemon as `primal_daemon` in `agents.yaml`, and start-up writes it at every start to `/etc/maceff/pd/<account>/declaration.json`, owned by root, mode 0644, in directories only root can write. Every reader uses that file when it exists, and the daemon refuses one that anyone but root could change. In a container, a declaration only in the agent's home no longer starts a daemon: start-up logs why. Hosts are unchanged. Eight new tests; five planted defects each caught.
