### Fixed

- **MANUAL_MODE no longer asks before every file write.** Returning to MANUAL_MODE put a bare `Write` back in the `ask` list, so every write prompted, the session scratchpad's included, and an operator working from a phone or a channel, who cannot see the dialogs, left the agent stalled (19 dialogs in two days on one seat). It now asks about edits under the user's home and `/opt` (`Edit(~/**)`, `Edit(//opt/**)`) and lets the session scratchpad under `/tmp/claude-<uid>/` through, and records which rules it added so the switch back to AUTO_MODE removes exactly those and the operator's own rules survive both ways. `mode_system` says which writes MANUAL_MODE asks about. The rule paths follow Claude Code's documented rule syntax and are not yet tried against a live prompt: the PR says what to test. Part of #876.
