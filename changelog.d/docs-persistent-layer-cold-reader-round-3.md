### Fixed

- **Persistent layer policy no longer contradicts itself on routes, read-back and crash loops** (`framework/policies/base/infrastructure/persistent_layer.md`). Sections 1.8 and 10.4 now agree with the code: a notice the daemon raises itself reaches the agent with no route, every route that would send one elsewhere is refused at load but `operator` for unread mail, and no warning is given at start for an unrouted `pd_schedule_changed`, since none is needed. Sections 1.8 and 10.6 state one read-back rule: a log with no checkpoint reads back a day, and an entry's wake older than that is owed again by the scheduler at every start. Section 1.2 says the agent-side mask is not applied while the operator's stream rules are. Sections 1.2 and 10.2 draw the line between a command the operating system refuses, which counts as a failure and raises `pd_unit_failed`, and a start the daemon declines before running anything, which raises nothing, and say where both and a `no_restart` exit show. Section 10.2 no longer says both that only the operator stops a crash loop and that the declaration stops a unit. Section 1.8 says the record check before owing uses the daemon's own copy of the channel's record, not the attached channel's hello.

### Changed

- **Persistent layer policy fills a cold reader's gaps** (`framework/policies/base/infrastructure/persistent_layer.md`). Section 10.6 defines the ask rule, revocation and the check-template rule where it first relies on them, and names the operator channel a report goes through. Section 11.4 gives the event socket's file name, says a rule's source takes globs and that `amail` and `pd_unread_mail` are silenced separately, says what a subscriber gets after a rotation, connected or reconnecting, and that `pd stream subscribe` takes `--position` and doesn't reconnect on its own. Section 1.5 says a notice logged delivered and never received has no automatic recovery, and gives the events query that finds it. Section 8 says there is no sanctioned way to read a peer's live state in a shared container, and to ask the operator. Each statement was checked against the code.
