### Added

- **A declaration lists the channels an organization allowlist admits** (`macf/src/macf/pd/allowlist.py`, `Declaration.allowlisted_channels`; MIS-0002-R124). Claude Code's `allowedChannelPlugins` replaces the default list, so a channel it leaves out, the operator's own included, stops loading at the next unattended restart. Each entry names its plugin and marketplace, as the client matches them. `pd install` refuses while the managed list and the declaration differ, naming each difference both ways, and refuses when the managed settings can't be read. The daemon compares again at start, says each difference on stderr and records one `pd_allowlist_mismatch` event, and runs on. A deployment with no allowlist needs no change. Planting four defects (one side of the comparison ignored, the `plugin@marketplace` string form dropped, an unreadable file read as no list, the daemon's event dropped) each failed a test.
