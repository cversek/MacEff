### Fixed

- **`agent init` says when the hooks, commands and skills are not installed, and names the command that installs them** (`agent_stack.py` `step_framework`, #1049, #860 item 4): `agent init` wrote the daemon, the harness and the channel, but the hooks and the `/maceff` commands come from `macf_tools framework install`, so a newcomer's agent started with no hooks bound and no commands, and neither the output nor the README said a second command was needed. A new `framework` step, before the daemon, looks for every hook event bound in the project's `.claude/settings.local.json` or the home's `.claude/settings.json`, and for a `/maceff` entry in the skills or the commands directory, and reports the step found with drift when either is missing, naming `cd <project> && macf_tools framework install`. It installs nothing itself, because that command works on the directory it is run from, and it never fails the run. A container's start step owns it, and `--no-framework` skips it.
