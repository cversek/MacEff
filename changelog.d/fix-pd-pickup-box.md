### Fixed

- **The primal daemon watches mail where the broker delivers it** (`amail/pickup.py`, `pd/notifier.py`, `pd/unread_mail.py`, `transcript_monitor/sources.py`, policy `persistent_layer`): it watched `<home>/amail/pickup`, a path no deployment creates, so a daemon detected no mail on any host or seat and said nothing. The box now comes from the rule `amail list` uses, each key on its own: `amail.json` when it has the key, else `MACF_AMAIL_HANDOFF` or `MACEFF_AGENT_NAME`, and the old path as a declared guess only with no agent name. A test holds the daemon and `amail list` to the same box. The daemon says at start which box it watches, and warns when the box is guessed or missing. A seat that runs a daemon needs an `amail.json` written at provisioning, since the outer tier passes no agent-configured variables.
