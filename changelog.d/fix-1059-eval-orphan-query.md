### Fixed

- **`knowledge eval` no longer stops with a traceback when a labelled artifact is outside the web** (`knowledge_eval.py`, #1059): the `like` ranker asked the web for an orphan, which names no node, and raised. An artifact outside the web can't be a query or a target, so it is left out of both and counted: the chart carries `orphan_queries`, `orphan_targets` and `no_target_queries` (queries whose only targets were outside the web) per source, and the report says how many were left out. A target the ranked list can never return would otherwise count as a miss for every ranker. On a corpus with orphans the dev and held splits are drawn from the artifacts in the web only, so a held set sealed before this change may read as changed since sealing, which the report already says when a corpus grows.
