### Added

- **`agent init` says where a seat's Telegram plugin keeps its poller files, and the watch looks where the session does** (`agent_stack.step_telegram_dir`, `pd.watch.session_places`, #1069): a new `telegram-dir` step (skip with `--no-telegram-dir`), for a declaration that names a Telegram channel, reports the plugin's state directory and what named it, and reports the account-wide default found with drift, naming `TELEGRAM_STATE_DIR` and the settings file to set it in, because the plugin ends an older poller when a newer one starts on the same directory, so an agent on the default can lose its bot to another agent or session on the login. It refuses nothing and writes nothing: which agents share the default is recorded nowhere. The directory is now resolved as the session gets it: the settings of the session unit's project directory (not only the agent home's), then the unit's declared `environment`, then the default under the unit's `HOME`. The watch's own process environment, which a daemon-started session never inherits, is no longer a source.
