### Added

- **`amail state <id>`: ask the broker where a message you sent stopped** (`amail/broker.py`, `amail/client.py`, `cli.py`, policy `amail` §6b.2, MIS-0004 R24). A new `state` operation on the broker socket answers from the disposition record: each recipient's latest state with its detail and time, and the message-level view derived from them. It answers only for the caller's own messages. Another agent's id reads `found: false`, the same as an unknown id, and an id the broker never mints is refused. The record stays readable from the filesystem with no broker running.
- **The broker socket carries a protocol version** (`amail/socket_protocol.py`, policy `amail` §3.2, MIS-0004 R35). Every request sends `v`, and every reply, refusals included, names the version that answered. A request with no `v` is version 1, which every existing client speaks. A version the broker doesn't speak is refused with the ones it does, and nothing in it runs. A protocol change lists the old version with the last day it is accepted. It's served with a `deprecated` note until then, and refused by name after.

### Changed

- **MIS-0004 R11, R16, R24, R35 and R37 are passing.** R11, R16 and R37 were already met by the code, so they gain the tests their rows name: the box copy stays until the recipient's store holds the message; a duplicate id is dropped and the drop recorded; and a hard-linked file and a file the recipient's group created are each refused and set aside. Each test was mutation-checked against the defect it names. R10's test passes for the broker-to-agent path, but its row stays planned: the shared hand-off rung writes into the peer broker's intake (#1168).
