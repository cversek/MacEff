### Added

- **`macf_tools pd unit start|stop|restart <unit> --reason TEXT`** (`pd/cli.py`, `pd/daemon.py`, policy `persistent_layer` 1.4): the control socket already took a start, stop or restart of one unit, and nothing on the command line sent one, so stopping a unit meant a script against `macf.pd.client.ask`. The verb names who asks (the agent inside a Claude Code session, the operator outside one, `--asked-by` to say otherwise), so the daemon now accepts `agent` as an asker for these acts, recorded beside the process the socket observed. It refuses an unknown unit and lists the declared ones, then reads the state back from the daemon: it exits non-zero unless the unit reached the state the act asks for within `--wait` (a restart needs a new process), and a restart held for a quiet window says so. A stop still doesn't outlive the daemon's next start (#1007).
