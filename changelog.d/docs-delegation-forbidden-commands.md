### Changed

- **Delegation prompts carry a forbidden list** (policy `delegation_guidelines` 1.2.0, new §3.6): a background subagent that runs any command needing approval, not only Write/Edit, stops until a person answers. Every prompt that can touch the host now names what the subagent must never run: container and service changes, privilege, deletes outside its scratch, publishing, installs outside a venv, secrets. It also tells a blocked subagent to report rather than work around. A deployment's own list lives in `~/agent/policies/personal/delegation.md`, pasted whole into each prompt. §3.2's example no longer grants a bare `pip install`, and §3.5's matrix adds the shell-command row.
