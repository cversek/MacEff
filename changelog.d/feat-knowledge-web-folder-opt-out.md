### Added

- **A folder can opt out of the knowledge web** (`knowledge_web.py`, `knowledge_doctor.py`, `cli.py`, policy `scholarship` §3.5.5): an empty `.not-in-knowledge-web` file in a type folder (a direct child of `agent/private` or `agent/public`, or a subagent's, or the task store wherever config or the environment moves it) takes the whole folder out of the walk; a marker deeper down has no effect, for material that is not an artifact, such as an archive or a scratch dump. The exclusion is never silent: `knowledge doctor` names each excluded folder in a note, and `knowledge status --json` lists them under `opted_out`. It is not a way to hide orphans; a folder of linkless artifacts stays in the web.
