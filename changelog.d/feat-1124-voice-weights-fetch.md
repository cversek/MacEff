### Changed

- **The speech weights are fetched by the operator, file by file, and the engine reads only the local cache** (`macf_tools voice models status|fetch`, `voice/speech/weights.py`, #1124): the MLX Kokoro engine used to download its weights from Hugging Face at its first start, from a daemon and unasked, and an offline first start fell back to the CPU model and stayed there until a start that happened online. `voice models fetch` lists the files the engine needs (the model's config and weights, and one file per voice the agent speaks in, 122 files and 389 MB being the whole repository) with their sizes, and fetches only the files named with `--approve` or answered yes to at a terminal, never a blanket flag. The engine sets the hub's offline switch before it loads, refuses to start on weights that were not fetched and says the command, and says the same for a voice that was not fetched instead of downloading it.
