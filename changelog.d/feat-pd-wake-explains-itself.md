### Changed

- **A held keystroke wake says why, and a dialog or draft hold keeps its screen** (`pd/wake.py`, `pd/watch.py`, `pd/daemon.py`, policy `persistent_layer` §1.9). Mail that arrives inside the ten-minute refractory window is now recorded as a `pd_wake_held` with the reason `refractory` and the seconds left (`left_s`), once per stretch. Before, it waited with nothing in the log, although the module said the window was "said once". A dialog or draft hold saves the captured pane, escape codes included, to `~/.maceff/wake_screens/`: the directory is private, each file mode 0600, the newest 20 kept. The hold names the file in `screen`. A pane that could not be read says `captured: false`. The outside watch treats a refractory hold as pacing: it never starts the 30-minute allowance and never raises `HELD`. So the alert to the operator comes no earlier than before, and a daily cap reached after the window doesn't page anyone.
