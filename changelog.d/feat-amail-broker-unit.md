### Added

- **`macf_tools amail broker-unit`: a host's broker as a declared unit of its own primal daemon** (`amail/host_daemon.py`, amail policy 7.5, MIS-0002 R53, MIS-0007 R81): writes the broker daemon's service identity (`AmailBroker_` with an id derived from the mail domain) and a declaration whose one unit runs the broker on the operator's configuration, into the configuration's directory by default, validated by the daemon's own declaration loader. Shown first, written with `--write`, a no-op when already current; a home that names another agent is refused. Prints the operator's steps: retire a launchd job that ran the broker directly (one broker per system), then `MACEFF_AGENT_HOME_DIR=<home> macf_tools pd install`. The same declaration takes an `export` section when the host gets a system daemon.
