### Added

- **Java and C++ language policies** (`lang/java/coding_standards.md`, `lang/java/testing_java.md`, `lang/cpp/coding_standards.md`), registered in the policy manifest as `JAVA_CODE`, `JAVA_TEST` and `CPP_CODE`. Java covers Android: logic in plain classes with no framework types, nothing waiting on the main thread, one shared contract per wire format, checked narrowing, named clocks, a pinned JDK toolchain, lint in CI, Error Prone strongly encouraged, Google Java Style with Javadoc for new and touched code. Java testing: local JVM tests first, no `returnDefaultValues`, fakes before mocks, known failures kept as `@Ignore` with their issue. C++ covers RAII and ownership, no silent narrowing, one timestamp type per clock, error codes in code loaded through JNI, a thin JNI layer with the reference, exception and thread rules, host GoogleTest, CheckJNI and HWASan. Each rule cites its primary source, and the rules that came from measured failures say so generically.
