### Added

- **The operator's registry of agents' keys and issued certificates** (`macf/amail/registry.py`, `amail registry check`, amail policy §3.2.3, MIS-0004 R42): each MacEff agent's public key is declared with its account in one root-owned file, `/etc/maceff/registry.yaml` by default, which also records each certificate the operator's authority issues by name, serial and expiry, never its key. A key an agent declared in its own contact list proved nothing to anyone else, since anything running as the agent could declare one. The registry is refused when read if anyone but root could write it or the directory that holds it, and a malformed entry is refused by name. It only declares: refusing unsigned agent mail (R43) and marking a failed signature suspect (R44) read it later.
