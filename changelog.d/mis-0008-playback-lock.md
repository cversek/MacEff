### Changed

- **Several agents speaking under one login** (MIS-0008 R27 to R29 as revised). Each agent runs its own speech worker (its lock now in the agent's voice folder), and one playback lock (`speech-playback.lock` in the daemon runtime directory) is held while a message plays, so two agents never speak at once and neither is shut out: after each message a worker leaves the lock a moment, so agents with queued messages take turns. A stop ends the wait. A message that waits 300 s for another agent is dropped, and its agent is told at its next prompt what the operator never heard, as with a cut (R55). Speaking and recording are also marked for the whole login, so no agent's capture unit wakes on another agent's speech and no agent speaks while another's microphone records. The runtime directory is per account, so this covers the whole system only where agents share one login, as on a Mac.
