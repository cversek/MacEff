### Fixed

- **The legacy pre-commit script no longer refuses a merge of main over handlers that are already on main** (`macf/scripts/pre-commit-hook.sh`, #1023): a commit that concludes a merge stages every file the other side changed, and the script's whole-file silent-exception check read each one and ignored `noqa` reasons, so a clean two-line change was refused for three reasoned handlers it had not touched. While `MERGE_HEAD` exists the check now stands aside and says so; the versioned style gate (`tools/style_check.py`'s ratchet) judges what the merge adds and honours a reasoned `noqa`. Every ordinary commit is still checked. A clone that installed this script as its own hooklet before the dispatcher existed keeps the old copy until it is refreshed (see CONTRIBUTING). Tests: a merge of main over a handler already on main passes, and an ordinary commit of the same handler is still refused.
