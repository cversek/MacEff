### Fixed

- **Keys typed into an agent's session reach the agent's own pane, not whichever pane has focus** (`supervisor.py`, `pd/wake.py`): `inject compact`, `auto-restart send-keys`, the compaction follow-up and the post-start keys now target the pane whose process is the supervisor, and the primal daemon's keystroke wake targets the pane the session unit created, named in its pane record. Before, both targeted the tmux session, which means its active pane, so after someone split the window and worked in the new pane (a task-tree watch beside the agent, say), every `/compact` and every wake went into that pane and never reached the client. Policy `persistent_layer` 1.9 already said the wake goes into "the session unit's own pane"; the code now does. A session without a matching pane falls back to the session as before.
