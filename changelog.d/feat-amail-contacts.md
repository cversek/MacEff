### Added

- **`macf_tools amail contacts`: an agent can list the correspondents it may write to** (GH#695, amail policy 4.1): the broker answers over its socket with each entry's address and direction (`both`, `outbound`, `inbound`, or `neither` for a withdrawn correspondent), scoped to the calling agent by the kernel-established identity (or the claim on a shared login, as `status` takes it), so an agent sees what the broker enforces now and never another agent's list. It carries identity and direction only, never a key, a push grant or a route; it is read-only and audited with its count; `[FILTER]` narrows by text and `--json` is for scripts. A broker with no contact list says so, and an older broker refuses the operation by name. Before this an agent could not find the address of a permitted correspondent it had not heard from, and had to guess one.
