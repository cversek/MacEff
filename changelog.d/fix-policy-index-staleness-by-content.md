### Fixed

- **The policy index's staleness check compares content, not times** (`utils/manifest.py`, `cli.py`, #898). A checkout re-stamps files whose content didn't change, so after a pull `policy recommend` said policies had changed when none had, and a policy restored with an old time was missed. `policy build_index` now records each policy's sha256 beside the index (`policy_index.lance.sources.json`), and the check reports a changed, new or removed policy by content. An index built before this, or from a directory named with `--policies-dir`, is still judged by time. The warning now also says to restart the search service, which keeps the index it loaded. The index's path is spelled once, in `get_policy_db_path`.
