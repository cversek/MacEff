### Fixed

- **`macf_tools env` and the hook's token section say when the context window is an assumed default** (`utils/tokens.py` `get_total_context_and_source`, `cli.py`, #1050, #860 item 7): with neither `MACF_CONTEXT_WINDOW` nor `context.window` set, the window silently fell back to 200,000, and CL levels and "approaching the boundary" warnings fired against that number on an account whose window is larger, so a new agent was told in its first session that it was nearly out of context. The resolver now reports where the value came from (`env`, `config` or `default`); `env` prints "assumed default, not read from your account" and how to set it beside a default value, `env --json` carries `context_window_source`, and the hook's `Tokens Used: x / 200,000` line carries the same label. A set value reads as before. This labels the fallback only; having `agent init` detect or ask for the window is not part of this change.
