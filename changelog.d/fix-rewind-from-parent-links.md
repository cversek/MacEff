### Fixed

- **The transcript monitor now notices a rewind** (#1003). It used to look for a transcript that got smaller, which a Claude Code rewind never produces: the client keeps the abandoned turns and appends the next prompt with a parent link that points back past them. A new per-monitor detector (`macf/src/macf/transcript_monitor/rewind.py`) reads those links and records `context_rewind_detected` when a typed prompt leaves three or more assistant entries behind. The event carries the branch point, the dropped span's first and last times and its size, and the tools used in it, with a Bash command named by its first program, so an agent can tell whether anything outward happened in turns it no longer remembers. It carries no text from the transcript. The monitor starts at the end of the file, so the detector first reads the file's last 8 MB; a rewind to a point older than that, or than the 50,000 entries it remembers, is not reported. Telling the agent at its next prompt is a follow-up.
